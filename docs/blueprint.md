# **App Name**: SkillUp

## Core Features:

- User Authentication: Secure user signup, login with 'remember me' functionality, and robust session management.
- Freelancer Profile Management: Users can create, edit, and view comprehensive freelancer profiles including avatar, bio, and skills.
- Customer Job Posting: Customers can post new job opportunities with details and requirements for freelancers to browse.
- Freelancer Search & Filtering: Customers can efficiently search and filter available freelancers based on specific skills or job categories.
- Real-time Messaging: An internal, real-time chat system enabling direct communication between customers and freelancers.
- Personalized Dashboards: Dedicated dashboards for freelancers and customers to manage profiles, view jobs, and track interactions.
- AI-Powered Matching Tool: An AI tool that suggests relevant freelancers for job posts or relevant jobs for freelancers based on their skills and profile data.

## Style Guidelines:

- Primary color: A deep, professional blue representing trust and efficiency (#2E66B3).
- Background color: A subtle, desaturated light bluish-gray providing a clean, spacious feel (#EEF1F5) for the default light scheme.
- Accent color: A vibrant, clear cyan-blue used for interactive elements and highlights, suggesting clarity and dynamism (#34C2D6).
- All text will use 'Inter', a modern sans-serif typeface, for its clean, objective, and highly legible appearance suitable for both headlines and body copy across all themes.
- Utilize a consistent set of modern, minimalist outline icons to maintain a clean and professional aesthetic throughout the application.
- Employ a mobile-first responsive design, ensuring a seamless user experience on all device sizes, including custom styles for light, dark, and AMOLED themes with persistent saving.
- Implement a clear and structured layout featuring a dedicated navigation sidebar, a professional homepage with a prominent hero section, and modern card components for organized content display.
- Incorporate subtle and smooth transition animations to enhance user interactions, improve perceived performance, and add a polished feel to the interface.
